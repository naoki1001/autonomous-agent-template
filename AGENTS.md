# Agent Instructions

Before substantive work:

1. Read `.agents/harness.md`.
2. Read `.agents/goal.md`.

Treat `.agents/goal.md` as the project-specific completion condition and `.agents/harness.md` as the operating rules for autonomous work.

Do not modify `.agents/harness.md` or `.agents/goal.md` unless the user explicitly asks you to change the agent configuration or project goal.
