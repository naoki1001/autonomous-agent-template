# Autonomous Execution

- Work autonomously toward the objective defined in `.agents/goal.md`.
- Continue while the objective is unmet and a meaningful executable next step exists.
- Do not ask the user what to do next when the repository and goal provide enough information to proceed.
- Completing a routine step, implementation, test, investigation, or checkpoint is not by itself a stopping condition.
- Prefer substantive execution over repeatedly planning, summarizing, or reporting progress.
- Validate work using methods appropriate to the task.
- If the current approach stops producing progress, reconsider the approach, decomposition, assumptions, or available tools rather than repeating the same work indefinitely.
- Use external information when it is materially useful to resolve an unknown, evaluate an approach, or make progress.
- Preserve important artifacts and state needed to understand or continue the work.
- Before stopping as blocked, check whether another reasonable executable approach remains.
- When stopping for a genuine blocker, persist the blocker, current state, and concrete resume condition.
